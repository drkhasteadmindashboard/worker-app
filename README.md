# دکتر خسته 🩺 — داشبورد دو نفره روی Cloudflare Workers (رایگان)

داشبورد مدیریت تسک و یادداشت برای دو ادمین، با ادغام کامل تلگرام (یادآوری خودکار موعد تسک‌ها + ربات) و بکاپ/هاست فایل روی گیت‌هاب. تمام سرویس‌های استفاده‌شده (Workers، D1، Cron Triggers) در پلن رایگان Cloudflare جا می‌شوند.

---

## 🚀 روش فوق‌العاده سریع و آسان: پیش‌نمایش محلی و دیپلوی در یک دقیقه

برای راحتی هرچه بیشتر شما، فرآیند اجرای محلی و دیپلوی ابری کاملاً خودکارسازی شده است. نیازی به اجرای دستورات متعدد در ترمینال ندارید؛ کافی است مراحل زیر را دنبال کنید:

### ۱. اجرای پیش‌نمایش روی کامپیوتر خودتان (Local Preview)
بدون نیاز به دیپلوی کردن، می‌توانید پروژه را به همراه دیتابیس محلی آن روی کامپیوتر خودتان اجرا کنید و پیش‌نمایش کامل را ببینید:
```bash
npm run preview
```
این دستور **به صورت خودکار دیتابیس محلی شما را مقداردهی اولیه کرده** و سرور توسعه‌ی کلودفلر (Wrangler) را اجرا می‌کند. پس از اجرای دستور، می‌توانید آدرس `http://localhost:8787` را در مرورگر خود باز کرده و پیش‌نمایش داشبورد را به طور کامل تست کنید.

### ۲. دیپلوی کاملاً خودکار و تعاملی (Interactive Deploy)
برای دیپلوی کردن پروژه به راحت‌ترین شکل ممکن، کافی است دستور زیر را وارد کنید تا اسکریپت هوشمند ما همه‌ی مراحل را برای شما انجام دهد:
```bash
npm run setup-deploy
```
**این دستور چه کارهایی برای شما انجام می‌دهد؟**
- شما را وارد حساب کلودفلر می‌کند (`wrangler login`).
- دیتابیس رایگان `D1` را به صورت خودکار برای شما می‌سازد.
- شناسه‌ی دیتابیس (`database_id`) را استخراج کرده و به صورت خودکار درون فایل `wrangler.toml` جایگذاری می‌کند.
- ساختار جداول دیتابیس واقعی کلودفلر را مقداردهی اولیه می‌کند (`db:init`).
- توکن ربات تلگرام و گیت‌هاب را از شما می‌پرسد و مستقیماً روی سرورهای کلودفلر به صورت سکرت امن ذخیره می‌کند.
- در نهایت کل پروژه را روی کلودفلر شما دیپلوی می‌کند!

## 💻 روش دوم: دیپلوی دستی از طریق داشبورد وب کلودفلر (بدون نیاز به دستورات ترمینال برای سکرت‌ها)

اگر ترجیح می‌دهید کنترل بیشتری داشته باشید و متغیرهای محرمانه و سکرت‌ها را به صورت مستقیم و بصری از طریق پنل وب کلودفلر تنظیم کنید (بدون نیاز به نوشتن دستورات CLI برای سکرت‌ها)، این روش را دنبال کنید:

### گام ۱: ساخت دیتابیس D1 در پنل وب
1. وارد حساب کاربری خود در [dash.cloudflare.com](https://dash.cloudflare.com) شوید.
2. از منوی سمت چپ به مسیر **Workers & Pages** -> **D1 SQL Database** بروید.
3. روی دکمه‌ی **Create database** و سپس **Create** کلیک کنید.
4. نام دیتابیس را دقیقاً `doctor_khaste_db` بگذارید و دکمه‌ی ایجاد را بزنید.
5. پس از ساخته شدن، مقدار **Database ID** (یک کد طولانی شبیه به `f85f19b1-49d3-49cd-bcc2-93a3b1ffd0a3`) را کپی کنید.

### گام ۲: به‌روزرسانی فایل تنظیمات
فایل `wrangler.toml` را در پروژه‌ی خود باز کنید و در بخش `[[d1_databases]]` مقدار کپی‌شده را جلوی `database_id` قرار دهید:
```toml
database_id = "شناسه_دیتابیس_شما"
```

### گام ۳: اولین دیپلوی و ساخت جداول
با اجرای دستورات زیر، پروژه را روی کلودفلر آپلود کرده و جداول دیتابیس ابری را بسازید:
```bash
# ورود به کلودفلر
npx wrangler login

# ساخت جداول دیتابیس ابری
npm run db:init

# دیپلوی پروژه
npm run deploy
```

### گام ۴: تنظیم آسان سکرت‌ها (Secrets) از طریق داشبورد وب کلودفلر
حالا نیازی به اجرای دستورات ترمینال برای سکرت‌ها ندارید! کافی است:
1. در پنل کلودفلر به منوی **Workers & Pages** رفته و روی ورکر دیپلوی شده‌ی خود به نام `doctor-khaste-dashboard` کلیک کنید.
2. به تب **Settings** (تنظیمات) بروید.
3. از منوی سمت چپِ تنظیمات، گزینه‌ی **Variables and Secrets** را انتخاب کنید.
4. در بخش **Environment Variables**، روی دکمه‌ی **Add** یا **Edit variables** کلیک کنید.
5. سه متغیر محرمانه زیر را اضافه کنید و دقت کنید که برای هر کدام دکمه‌ی **Encrypt** (رمزنگاری) را فعال کنید تا به سکرت تبدیل شوند:
   - `TELEGRAM_BOT_TOKEN`: توکن دریافتی از BotFather.
   - `TELEGRAM_WEBHOOK_SECRET`: یک رشته‌ی متنی تصادفی و دلخواه (مثلاً `my98h3yWWsecret`).
   - `GITHUB_TOKEN`: توکن دسترسی شخصی گیت‌هاب (Personal Access Token) برای بکاپ‌ها.
6. روی دکمه‌ی **Save and Deploy** در پایین صفحه کلیک کنید تا تغییرات فوراً اعمال شوند.

## 🛠️ روش سوم: دیپلوی مداوم با گیت‌هاب (CI/CD GitHub Actions)

اگر می‌خواهید هر زمان که کدی را به مخزن گیت‌هاب خود پوش (Push) کردید، پروژه به صورت خودکار دیپلوی شود، مراحل زیر را دنبال کنید:

1. به تنظیمات مخزن گیت‌هاب خود بروید (**Settings** -> **Secrets and variables** -> **Actions**).
2. دو سکرت جدید با مشخصات زیر بسازید:
   - `CLOUDFLARE_API_TOKEN`: توکن امنیتی کلودفلر با دسترسی ویرایش ورکرز (می‌توانید آن را از بخش API Tokens پنل کلودفلر بسازید).
   - `CLOUDFLARE_ACCOUNT_ID`: شناسه‌ی حساب کاربری کلودفلر شما (موجود در داشبورد اصلی کلودفلر).
3. اکنون با هر بار پوش کردن روی برنچ `main`، گیت‌هاب پروژه را به صورت کاملاً خودکار روی ورکر کلودفلر دیپلوی خواهد کرد! فایل کانفیگ این قابلیت در مسیر `.github/workflows/deploy.yml` قرار دارد.

## 📖 راهنمای گام‌به‌گام راه‌اندازی و اتصال‌ها (بعد از دیپلوی)

### مرحله ۱: اتصال وبهوک تلگرام
با مقدار `TELEGRAM_WEBHOOK_SECRET` (که در بخش سکرت‌ها تنظیم کردید) و آدرس Worker دیپلوی شده‌تان، این آدرس را یک بار در مرورگر خود باز کنید:
```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://YOUR-WORKER-URL/telegram/webhook/<TELEGRAM_WEBHOOK_SECRET>
```

### مرحله ۲: راه‌اندازی اولیه داشبورد
1. آدرس Worker خود را در مرورگر باز کنید. به دلیل نبود ادمین، صفحه‌ی **راه‌اندازی اولیه** را خواهید دید.
2. نام، نام کاربری و رمز عبور خود را وارد کنید تا به صورت خودکار **ادمین اصلی** شوید.
3. پس از ورود به داشبورد، از بخش «ادمین‌ها» می‌توانید ادمین دوم (همکار یا همسر خود) را بسازید.
4. هر کدام از ادمین‌ها می‌توانند از بخش «تنظیمات -> اتصال تلگرام» دکمه دریافت کد را بزنند و کد خروجی را به صورت `/start CODE` به ربات ارسال کنند تا سیستم پیام‌رسان و یادآور تلگرام برای آن‌ها فعال شود.

## امکانات کلی سیستم
- ورود چند ادمین، با یک **ادمین اصلی** که تنها او می‌تواند ادمین جدید بسازد یا حذف کند.
- تسک با عنوان، توضیح، موعد، اولویت، واگذاری به ادمین، و وضعیت (در انتظار/در حال انجام/انجام‌شده).
- **تقویم** ماهانه با نقطه‌های رنگی روی روزهای دارای موعد.
- **یادداشت‌ها** با رنگ دلخواه هر ادمین و نمایش نام + رنگ اختصاصی نویسنده روی هر کارت.
- **ربات تلگرام**: اتصال حساب با کد یک‌بارمصرف، دستور `/tasks` برای دیدن تسک‌های باز، و ارسال خودکار یادآوری یک روز قبل، روز موعد، و هشدار تسک عقب‌افتاده (هر ۳۰ دقیقه بررسی می‌شود).
- **بکاپ خودکار روزانه به گیت‌هاب** (ساعت ۰۲:۰۰ UTC) + دکمه بکاپ دستی، و همچنین امکان آپلود فایل که مستقیم در ریپازیتوری گیت‌هاب ذخیره و از طریق لینک خام (raw) قابل نمایش است.
- طراحی مدرن، تیره، راست‌به‌چپ و کاملاً فارسی.
